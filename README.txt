НАБИТЕК — WordPress theme
==========================

Установка:
1. В WordPress: Внешний вид → Темы → Добавить новую → Загрузить тему.
2. Загрузите nabitek-theme.zip.
3. Активируйте тему.
4. Откройте Внешний вид → Настроить → НАБИТЕК — Контакты и при необходимости измените телефоны/адреса.
5. Для страницы главного экрана используйте статическую главную страницу. Шаблон front-page.php выводит лендинг автоматически.

Что внутри:
- Адаптивная главная страница по предоставленному макету.
- Цвета и типографика из брендбука: оливковый, терракотовый, песочный, молочный, графит; Inter + Playfair Display.
- Собственные типы записей «Проекты» и «Отзывы».
- Мобильное меню.
- Модальная форма консультации через wp_mail.
- Все предоставленные изображения и паттерн бренда включены в assets/.
